# 定性表述参考索引（references/qualitative-guide/）

## 本目录是什么

审计署《审计常用定性表述及适用法规向导》系列的**可检索索引**，供撰写问题标题与定性表述时取用官方措辞骨架。

**不是法规库。** 法规依据一律以 `references/laws/` 结构化法规库为准。

## 数据结构

每行一个 JSON 对象：

```json
{"domain":"企业审计（2021年修订）","level":"item","code":"2.3.4","wording":"未按规定履行招标程序","part":null,"parent":"2.3"}
```

- `level`：`category`（上位类别）或 `item`（具体表现形式／定性表述）
- `code`：原件章节号，可直接回原件定位
- `parent`：所属类别的 code，用于聚类

检索示例：

```bash
grep 询价 index/q-fixed-asset.jsonl
grep 公务接待 index/q-enterprise-2021.jsonl
```

## 使用红线

1. **不得照抄向导所附法规条文**——其条文以编制基准日有效为准，且向导自述“不应机械照搬”。引用法规另经 `references/laws/` 过滤。
2. **不得直接照搬整句**——须替换为本项目主体、期间、笔数、金额与具体标的。
3. **不得因引用而升级定性**——向导表述多为已定性口径（违规／未按规定），证据只达“管理不规范”时须降级。
4. **分类仍按 `rules/classification.md`**——向导的分类体系与 12 主类不同。

规则全文见 `rules/evidence-and-wording.md`「定性表述参考索引」。

## 生成方式与已知局限

由脚本从原件正文的编号标题（`X.Y.Z 表述`）抽取，按 code 去重、取最短表述；目录折行与“编号单独一行”格式已做合并处理。

已知局限：

- **抽取自编号标题，非全量人工校对**；个别领域（如国外贷援款、教科文卫）上位类别较少，因原件的类别层级不是标准 `X.Y` 编号；
- 表述文本存在原文 OCR/换行造成的个别字符缺失，正式引用前应回原件核对；
- 「自然资源审计」与「资源环境审计」原件内容基本重复，只保留后者；
- 「河南省财政行政处罚裁量基准」（豫财法〔2021〕3号）不是定性向导，未纳入本索引（属处罚裁量规则，需要时单独引用）。
