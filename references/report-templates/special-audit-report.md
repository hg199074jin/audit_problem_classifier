# 模式 B：专项审核报告

> 本模板继承 V1 成熟报告结构，但所有格式统一读取 `profiles/firm-default.yaml`；模板不得覆盖 HARD-GATE、分类、证据、金额和法规适用规则。

适用场景：会计师事务所受托出具的财务收支专项审核报告、内审机构专项审计报告。模式A（分类整理报告）与模式B的选择，经《待决策事项清单》与用户确认后确定。

## 一、报告骨架

| 部分 | 要素 |
| --- | --- |
| 封面页 | 被审计单位全称（加粗居中）→ 报告名（如《财务收支专项审核报告》）→ 文号（居中）→ 城市（如"中国·郑州"）→ 出具机构名称；全部居中 |
| 目录页 | Word 目录域（交付时提醒用户打开后更新域/F9） |
| 正文眉首 | 被审计单位名（可两行）→ 报告名（二号字居中）→ 文号 → **主送单位**（顶格、冒号结尾）→ 两段导语 |
| 正文五章 | 一、委托目的／二、本单位概况／三、审核中发现的主要问题／四、意见和建议／五、报告使用范围 |
| 签字盖章页 | "（此页无正文，为审计报告签字盖章页）"→ 机构名称 → 注册会计师/审计组组长 → 城市 → 日期 |
| 页眉页脚 | 页眉=单位名+报告名+文号；页脚=机构联系方式+页码（占位待填） |

导语两段固定套路：

1. "我们接受委托，对××（以下简称'××'）××期间（YYYY/MM—YYYY/MM）的财务收支及相关经济活动的合规性进行了专项审核。"
2. "贵单位对所提供会计资料及相关文件的真实性、完整性负责。我们的责任是依据××实施审核，通过抽查会计凭证、核对原始附件、比对供应商工商信息、复算报销与结算金额、延伸核对业务资料等程序获取充分证据，并在此基础上形成审核结论。现将审核结果报告如下："

## 二、"审核中发现的主要问题"的组织

- 开头一段简要总体评价（如"财务管理和内部控制制度框架基本建立，各项业务开展总体有序，会计核算执行政府会计准则制度。但审核发现……存在薄弱环节，应当引起足够重视并加以改进。"），程式化表述、可按实际调整。
- 二级标题按业务大类（（一）预算管理类、（二）收入与非税收入管理类、（三）政府采购类……），每类内小项从 1 重新编号。
- **小项三段式**：
  1. **定性结论式标题**：如"取得的业务结算款直接冲减费用，收入费用反映不实"。不照抄凭证摘要，不用"账务处理不规范"类行为概括式；
  2. **导语句 + 具体情况**：一句概括（含笔数、金额），以"具体情况如下："引出表格，或 ≤3 条时逐笔文字陈述；
  3. **法规段**：小项末尾集中一段，"上述事项不符合《法规全称》（文号）第X条'条文原文'的规定"，一段内可并列多依据（直接依据在前、上位法补充在后）。

## 三、表格与文字的触发规则

- 同一小项问题 **超过 3 条：正文插表格**；≤3 条：文字逐笔陈述（每笔含日期、X号凭证、摘要、金额、开票单位）；
- 表格 6 列：`凭证日期 | 凭证号 | 摘要 | 涉及金额（元） | 开票单位 | 问题描述`；
- 日期列一律 YYYY/MM；无金额、无凭证的写"-"；金额千分位两位小数；红字冲销按正数陈述业务实质；
- 表头灰底、跨页重复表头；表格后紧跟法规段；
- "问题描述"列写具体违规点，与表格已有字段（日期、凭证号、摘要、金额）不重复。

## 四、"意见和建议"的写法

- 按与问题部分对应的大类分组，每类：1 句总述 + 若干条目；
- 条目格式：`1．标题（机制式短语）。正文`；正文写具体操作机制——台账管理、年度归集、岗位分离、四单匹配（合同/验收/发票/付款申请）、勾稽核对、审批权限、追收补收，不写空泛口号；
- 定性审慎句式："不能仅以……直接认定为……""进一步核实后依法依规处理""不得简单将……混同为……"。

## 五、"报告使用范围"（事务所标准表述）

本报告仅供××内部管理使用；非经法律法规规定，报告全部或部分内容不得提供给其他任何单位和个人，不得见诸公开媒体；因报告使用不当造成的一切后果与本事务所及注册会计师无关。（按业务约定书调整）

## 六、正式稿禁项（交付前逐项自查）

1. 占位符【】清零（文号、主送单位、委托方、机构名、日期、联系方式）；
2. 底稿疑问句（"？""待落实""是否……"）不得保留，改为确定事实或移入待核实事项；
3. 拆分重组后旧章节删除，不得前后重复；
4. 英文直引号清零，日期全文唯一格式（YYYY/MM）；
5. 数量×单价、分项合计与总额逐笔勾稽，差额必须说明；
6. 每个小项法规段恰好一段、条款号与条文原文完整。
