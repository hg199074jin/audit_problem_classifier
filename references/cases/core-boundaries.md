# 核心边界案例

> 本文件是非规范性示例。发生冲突时，规则文件优先：分类看 `rules/classification.md`，证据措辞看 `rules/evidence-and-wording.md`，法规适用看 `rules/law-applicability.md`。

## FY / KJ / SW
- 报销缺名单、验收、配送明细，核心是支出真实性和费用承担：通常作为 FY Finding。
- 核心错误是科目、确认计量或账实账表关系：作为 KJ Finding。
- 核心错误是扣缴义务或发票法定效力：作为 SW Finding。

## 报价异常 ≠ 串通投标认定
联系人、邮箱、股东关联、报价规律一致，只能支持“存在串通报价嫌疑/真实性存疑”；没有意思联络、利益安排或有权机关认定等进一步证据时，不写“构成串通投标”。

## 占用 ≠ 挪用
应缴款余额大于可用存款，可以说明未及时足额上缴、部分应缴资金被占用；要写“截留、挪用”还需要资金流向和行为证据。

## 少收 ≠ 损失
款项仍具有追收条件时写“少收应收款项”；只有已经形成现实且难以追回的经济后果，才考虑“造成损失”。

## 补签 ≠ 倒签
先履行、后签合同写“事后补签/先履行后签订书面合同”；日期被人为倒填且证据充分时，才使用“倒签”。

## 地方采购阈值不能关键词套用
河南采购阈值必须由 Project Context 的单位层级、城市、采购类型、金额和业务年度共同过滤；不能把省级/郑州市本级标准直接套给开封市级或县级单位。
