# 决策比对"未见事项"的被查单位核对确认 + 国企审计法规库补齐

> 日期：2026-11-20
> 状态：**APPROVED**（用户裁定；背景为开封水投集团 2026 年预算执行检查项目的 V1+DeepSeek 产出与 V2.2.4 产出的实盘对照）
> 效力：`rules/decision-gate.md` 新增必须阻断第 8 项及核对确认程序；`references/laws/national/` 新增 9 个国企审计法规对象。变更随下一次版本发布流程整体收口，本记录不单独触发版本号。

## 1. 背景（真实项目对照发现的两个缺口）

开封水投项目同一批底稿分别由旧引擎（V1 skill + DeepSeek）与新引擎（V2.2.4）产出报告。对照发现：

**缺口一（程序缺口）**：旧项目把"账面单笔 30 万元以上付款 vs 集团党委会纪要〔2026〕1—23 号"比对出的约 30 笔"未见"事项，经**被查单位核对确认**后收敛为 5 笔、金额 2,405,269.00 元（其余均有内部会议记录佐证），事实段明确写"经被查单位核对确认"。V2.2.4 因缺少该程序约束，基于底稿比对状态直接列示 24 笔、20,070,100.78 元为正式问题（仅加口径警示），口径显著偏宽。比对结论 ≠ 违规事实，必须经核对确认程序闭环。

**缺口二（法规库缺口）**：旧项目为国企审计引用了《企业国有资产法》第三十条、企业内控应用指引第 3/6/7/15/16 号、《企业会计准则——基本准则》、《必须招标的工程项目规定》第五条、财企〔2009〕242 号等恰当依据，但这些对象均不在 V2 结构化法规库中，导致 V2 报告只能大量标注"法规依据需人工核验"。另对照发现旧产出存在法规时效错误（发票管理办法沿用 2023 年修订前条号）、主体适用错误（对企业内部预算问题引用《预算法》第十三条）、条号错误（基本准则可靠性条款实为第十二条而非第十条）——说明"选对法规体系"与"选对版本/条号"需要结构化库同时保障。

## 2. 用户裁定（2026-11-20 APPROVED）

1. 补齐国企审计法规库：将上述经官方来源逐字核实的法规对象纳入 `references/laws/national/`；
2. 将"被查单位核对确认"写入 HARD-GATE：未见纪要事项未经核对确认不得进入正式问题、不得计入正式问题金额合计。

## 3. 规则变更

- `rules/decision-gate.md`：必须阻断清单新增第 8 项；新增"决策比对'未见事项'的被查单位核对确认"一节（四步程序 + 金额汇总禁令）。
- `references/laws/national/` 新增 9 个对象（均满足 schema、官方来源、verified=true，verified_at=2026-11-20）：
  - `CN-SOE-ASSETS-LAW-2008-ART30`（企业国有资产法第三十条，唐山市政府网官方转载）
  - `CN-IC-GUIDE-3-HR-2010` / `CN-IC-GUIDE-6-FUNDING-2010` / `CN-IC-GUIDE-7-PROCUREMENT-2010` / `CN-IC-GUIDE-15-BUDGET-2010` / `CN-IC-GUIDE-16-CONTRACT-2010`（企业内控应用指引，财政部会计司财会〔2010〕11号原文 PDF 逐字核对）
  - `CN-EAS-BASIC-ART12`（企业会计准则——基本准则第十二条，财政部条法司现行文本）
  - `CN-MANDATORY-TENDER-NDRC16-ART5`（必须招标的工程项目规定第五条，发改委官方公开 PDF 逐字核对）
  - `CN-WELFARE-FEES-2009-242`（财企〔2009〕242 号货币化改革部分，黄浦区政府官方转载 + 长春市财政局官方解读双重确认）

## 4. 适用性设计要点

- 企业通用类（内控指引×5、基本准则、242 号）：`excludes_if: organization.is_public_institution eq true`——行政事业单位硬排除；**排除事实缺失时按引擎语义 fail-closed 到 needs_review**，因此 Project Context 必须设置 `organization.is_public_institution`（国企项目设 false 即可达 applicable，事业单位设 true 即硬排除，性质不明则转人工核验）。
- `CN-SOE-ASSETS-LAW-2008-ART30`：`applies_if: organization.is_state_owned + matter.major_capital_operation`，缺失时 needs_review（防主体/事项误引）。
- `CN-MANDATORY-TENDER-NDRC16-ART5`：`applies_if: project.within_mandatory_tender_scope eq true`——第五条以第二至四条适用范围为前提，防止对非强制招标项目套用（防"预算法式"主体误引）。
- **中办发〔2010〕17 号（"三重一大"）不纳入结构化库**：该文件属未全文公开的内部文件，无法满足 `source.type=official + verified=true` 的入库门槛；涉及"三重一大"问题继续按现行做法标注"法规依据需人工核验"。官方可溯痕迹：国资委《关于公布现行有效的规范性文件目录的公告》载有配套通知（国资党委纪检〔2010〕177 号）。

## 5. 影响与未尽事项

- 内控指引施行范围是分步的（2011-01-01 境内外同时上市公司 → 2012 主板上市公司 → 鼓励非上市大中型企业执行），`identifier` 已注明；对非上市国企按"鼓励执行 + 国资监管要求"作为直接依据引用时，建议在报告行文中保留"参照"表述。
