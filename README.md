# 审计问题报告化助手

面向中小会计师事务所的收支审计、合规审计问题整理 skill，用来把查出来的问题整理成审计报告可用的问题段落、问题分类、候选法规依据和审计建议。

当审计人员已经查出问题，但原始问题清单比较口语化、零散或不适合直接写入审计报告时，可以使用本 skill 进行：

- 公文式问题重述
- 审计问题分类
- 候选法规制度依据匹配
- 审计建议生成
- 问题清单整理为报告结构

## 适用场景

- 行政事业单位收支审计
- 财务收支审计
- 合规审计
- 专项资金检查
- 政府采购、资产管理、费用支出检查
- 整改问题清单整理
- 审计报告问题段落润色和规范化

## 能处理的问题类型

当前内置分类包括：

- `ZD` 重大政策落实类
- `YS` 预算决算类
- `ZJ` 资金管理类
- `ZC` 资产管理类
- `CG` 政府采购类
- `XM` 项目管理类
- `FY` 费用支出类
- `SJ` 审计监督类
- `KJ` 会计基础类
- `NK` 内部控制类
- `SW` 税务票据类
- `QT` 其他问题类

## 使用示例

```text
请使用 $audit-problem-classifier 整理下面的审计问题清单，要求按问题分类、公文式重述、列出候选法规依据，并提出审计建议。

1. 2024年某单位购买办公设备，金额8.6万元，没有走政府采购，直接找供应商买的。
2. 某单位报销会议费3.2万元，附件只有发票，没有会议通知、签到表和审批单。
```

## 输出内容

默认输出包括：

1. 问题分类汇总表
2. 分类问题详述
3. 候选法规依据
4. 管理建议
5. 需人工核验事项

## 重要规则

- 如果问题描述不清楚，skill 应先追问，不直接定性。
- 不编造金额、凭证号、合同号、发票号、审批过程或法规条款。
- 法规依据不确定时，标注“法规依据需人工核验”。
- 输出结果应由审计人员最终复核后再用于正式报告。

## 安装方式

将整个 `audit-problem-classifier` 文件夹放入 Codex skills 目录，例如：

```text
~/.codex/skills/audit-problem-classifier
```

Windows 通常为：

```text
C:\Users\<用户名>\.codex\skills\audit-problem-classifier
```

放入后重启 Codex，使 skill 被重新加载。

## 维护建议

建议根据实际项目继续补充：

- 当地财政、审计、机关事务等部门制度文件
- 常用审计报告问题段落
- 本所内部报告格式要求
- 常见问题对应的整改建议

地方性法规和制度建议单独整理到 reference 文件中，避免和通用法规混在一起。
