# 报告格式硬规则

本规则只处理**最终交付文字格式**，不改变事实、分类、金额口径或法规判断。格式规则属于硬约束，必须在最终输出前执行。

## 固定规范

- 日期：报告正文统一使用 `YYYY/MM`。例如 `2025.5.31` 应规范为 `2025/05`。
- 金额：需要列示具体金额时使用千分位和两位小数，例如 `2,300.00元`。
- 引号：中文正文中的项目名称、摘要、文件名等使用中文弯引号 `“……”`，不得保留 ASCII 直引号 `"……"`。
- 凭证引用：报告正文统一写成 `X号凭证`。输入材料中的 `记账-66号凭证`、`转账-66号凭证` 等账簿类型前缀仅作为 Source Record 原始信息保留，正式报告写作时规范为 `66号凭证`。

## 最终格式自检

完成报告正文后，必须再做一次独立格式检查，不能依赖“前面已经注意过”。

仓库提供：

```bash
python scripts/report_format_lint.py <report-text-file>
```

等价的 runtime 自检至少包括：

1. 中文正文是否还存在 ASCII 直引号；
2. 是否还存在 `记账-X号凭证`、`转账-X号凭证` 等未规范凭证引用；
3. 是否还存在 `YYYY.M.D` 等点号日期。

若 lint 发现上述问题，必须先修正，再交付最终报告。
